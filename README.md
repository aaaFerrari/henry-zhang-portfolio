# Henry Zhang — Art & Game Portfolio

A static bilingual portfolio for Henry Zhang / 张惟楚.

## Browse

Open `index.html` locally, or publish this repository with GitHub Pages. The first visit defaults to English. The English / 中文 buttons switch all interface and project text and remember the visitor’s preference. Images retain their original artwork text.

## GitHub Pages

Publish from the `main` branch and `/ (root)` in Settings → Pages. `.nojekyll` keeps this plain HTML, CSS and JavaScript website buildless. All asset URLs are relative, so project URLs work without a custom domain.

## Content

- `content.js`: Chinese content.
- `content.en.js`: English content with matching IDs and media paths.
- `i18n.js`: language selection and persistence.
- `gallery-refinements.css`: aligned portfolio covers and equal-sized gameplay stills.
- `assets/`: artwork, the four original portfolio PDFs, practice PDFs and the DATA FURNACE walkthrough video.

The site contains About, Drawing, 3D Studies, Portfolio and Collaboration. CYPHER screenshots are static images; the demonstration is linked separately. The DATA FURNACE walkthrough is an actual video with playback controls.

## Editing

Edit the matching Chinese and English data records together. No dependency installation or build is required. Commit and push changes to `main` to update GitHub Pages. Keep media paths and filename capitalization intact.

Artwork and personal content remain with their respective rights holders. No license for reusing artwork is granted by this repository.
